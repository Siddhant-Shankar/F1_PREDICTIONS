    How a call gets made.

    The same pipeline runs before every race, trained only on what happened earlier, so no forecast on this site has seen its own result.

    1. Features

      Qualifying pace, recent form, Elo-style ratings and circuit history, each built from sessions before the race.

    2. Ranker

      A LightGBM LambdaRank model orders the grid. It trains on classified finishers only, so a gearbox failure doesn't read as slow pace.

    3. Ensemble

      The ranker is blended with a finishing-position regressor and the starting grid itself.

    4. Simulation

      Plackett–Luce sampling turns scores into chances to win, reach the podium and score points.
